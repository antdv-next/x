# @antdv-next/x-pro

Community-driven agent components for [Antdv X](https://github.com/antdv-next/x).

> **Unofficial community package**: not ported from, affiliated with, or synced to the Ant Design X upstream. Everything here is original community work.

## Components

- **MessageScroller** — conversation scroll container with streaming follow, rail navigation and back-to-latest, plus an `XProProvider` for package-level component config and locale.
